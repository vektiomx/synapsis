# Nueva capacidad de Synopsis

Aplicar [discovery](playbook_discovery_first.md) y consultar el catálogo. Definir
contrato, consumidor, persistencia y comportamiento cuando falten capacidades.
Ubicar el cambio en módulos existentes antes de crear nuevos. CLI/MCP/adaptadores
dirigen el transporte; lógica y persistencia reutilizan servicios del motor.
No imponer la arquitectura Laravel de Meximova a Python.

Comprobar alcance por proyecto, revisiones, idempotencia, errores recuperables,
compatibilidad de datos y ausencia de ejecución desprotegida. Añadir pruebas que
comprueben resultados y fallos relevantes. Actualizar la documentación de producto
correspondiente y cerrar con [definition_of_done](../checks/definition_of_done.md).
